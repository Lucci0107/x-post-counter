# Xポスト文字数カウンター

X投稿文の文字数、X換算、文字種比率、タイムライン表示を確認するための静的Webアプリです。

## 機能

- 半角0.5、全角・絵文字1、改行0.5、URL11.5でX換算（複合絵文字も1文字）
- 漢字、ひらがな、全角カタカナ、英数字、その他比率の表示
- 読みやすい文章の黄金比率から外れた項目を赤文字表示
- 改行・半角スペース・段落構造に基づくタイムラインの近似表示
- 全文詳細表示
- コピー、クリア、半角スペース・改行の削除
- 定型文・ハッシュタグの追加、編集、挿入、削除
- 画像のプレビュー
- 下書き・定型文・テーマをブラウザに保存
- X投稿画面へのリンク（本文はコピーしてX側で貼り付け）

X換算は半角0.5を基準にした、このアプリの表示単位です。入力文字数と文字種比率はコードポイント数で計算します。URL検出とタイムライン省略は近似で、X上の表示を完全には再現しません。

## ローカル確認

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

`http://127.0.0.1:4173` を開いて確認します。`Intl.Segmenter` に対応したブラウザが必要です。

## テスト

Node.js 20以降で、追加のパッケージを入れずに実行できます。

```bash
node --test tests/counter.test.cjs
git diff --check
```

## 公開

公開先: [Xポスト文字数カウンター](https://x-post-counter.netlify.app/)

既存のNetlifyサイトにアップロードして公開しています。ビルドは不要で、`netlify.toml` の公開ディレクトリはリポジトリルートです。手動公開では `index.html` と `favicon.svg` の2ファイルを公開用フォルダーにコピーし、そのフォルダーを指定します。

```bash
netlify deploy --dir <公開用フォルダー> --no-build
netlify deploy --dir <公開用フォルダー> --no-build --prod
```

プレビュー確認後に本番を更新します。`.netlify/` は接続情報としてローカルに残し、Gitには含めません。
