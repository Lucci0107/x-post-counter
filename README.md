# Xポスト文字数カウンター

X投稿文の文字数、残り文字数、文字種比率、タイムライン表示を確認するための静的Webアプリです。

## 機能

- 入力欄の直下にX換算と残り文字数を表示し、140文字を超えると超過分を赤文字表示
- 公式の `twitter-text` でURL・日本語・絵文字・記号・アクセント文字を換算
- 漢字、ひらがな、全角カタカナ、英数字、その他比率の表示
- 読みやすい文章の黄金比率から外れた項目を赤文字表示
- 改行・半角スペース・段落構造に基づくタイムラインの近似表示
- 全文詳細表示
- コピー、クリア、半角スペース・改行の削除、直前のクリア・空白削除の取り消し
- 定型文・ハッシュタグの追加、編集、挿入、削除（パネルは初期状態で折りたたみ）
- 画像のプレビュー
- 下書き・定型文・テーマをブラウザに保存。保存が失敗しても編集・計算・コピーを継続し、画面内の変更を保持
- X投稿画面へのリンク（本文はコピーしてX側で貼り付け）

X換算は公式ライブラリの文字数を2で割った、このアプリの表示単位です。通常の上限280を140として表示します。半角英数字などは0.5、日本語・絵文字は1、改行は0.5、URLは11.5です。半角カタカナも日本語の重みで数え、`ｶﾞﾊﾟ` は4になります。URL直後の日本語・句読点や、ドメインだけのURLも公式ルールで判定します。

入力文字数と文字種比率は元のコードポイント数で計算します。タイムライン省略は近似で、X上の表示を完全には再現しません。

取り消しは直前のクリア・空白削除1回が対象です。クリア前の画像と本文の選択範囲も戻します。新しい入力・画像選択・本文への定型文操作を行うと、古い取り消し履歴は無効になります。画像と取り消し履歴は再読み込み後には復元しません。保存失敗の案内が出た場合は、画面を閉じる前に必要な本文をコピーしてください。

## ローカル確認

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

`http://127.0.0.1:4173` を開いて確認します。`Intl.Segmenter` に対応したブラウザが必要です。

## テスト

Node.js 20以降で、追加のパッケージを入れずに実行できます。配信用ライブラリをリポジトリに含めています。

```bash
npm test
git diff --check
```

GitHub Actionsでも、コード変更のpush・プルリクエスト時にNode.js 20 / 24で回帰テストを実行し、配信用ライブラリの再生成結果が一致するか確認します。

## 公式ライブラリの更新

`vendor/twitter-text.js` は `twitter-text` 3.1.0から必要な機能だけをまとめた、約30KBの配信用ファイルです。外部CDNには依存しません。ライセンスは `vendor/THIRD_PARTY_LICENSES.txt` に同梱しています。

バージョン変更時は `package.json`・`package-lock.json` を更新し、次を実行して生成物とテスト結果を確認します。通常の起動・公開にはこの工程は不要です。

```bash
npm ci --ignore-scripts
npm run vendor
npm test
```

## 公開

公開先: [Xポスト文字数カウンター](https://x-post-counter.netlify.app/)

既存のNetlifyサイトにアップロードして公開しています。ビルドは不要で、`netlify.toml` の公開ディレクトリはリポジトリルートです。手動公開では `index.html`・`favicon.svg`・`vendor/` を公開用フォルダーにコピーし、そのフォルダーを指定します。`vendor/` の入れ忘れは起動エラーになるため、配信用JSとライセンスを両方含めます。

```bash
netlify deploy --dir <公開用フォルダー> --no-build
netlify deploy --dir <公開用フォルダー> --no-build --prod
```

既存サイトへの本番反映は承認後に行います。`.netlify/` は接続情報としてローカルに残し、Gitには含めません。現在の実装・公開状況は `DEVELOPMENT_STATUS.md` を参照してください。
